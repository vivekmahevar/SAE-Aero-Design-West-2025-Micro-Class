# SAE-Aero-Design-West-2025-Micro-Class
Design and development of a Micro Class fixed-wing RC aircraft for SAE Aero Design West 2025.

MATLAB Design Tools


These MATLAB scripts were originally developed during the SAE Aero Design West 2025 project to support conceptual aircraft design, performance calculations, and sizing. The same computational framework was later adapted and reused for subsequent aircraft design competitions, including Techfest IIT Bombay and NACDeC IX, with project-specific input parameters and design requirements.
